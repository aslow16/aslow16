## État du pilote

La vidéo reste un **brouillon** : la voix eSpeak NG est mécanique et les faits restent à vérifier dans les sources avant publication sur la chaîne. Le bandeau de brouillon est conservé dans les deux vidéos. Les schémas sont des illustrations simplifiées, pas une reproduction officielle du drapeau.

L’ajout de ce dossier à GitHub permet de récupérer les fichiers. Aucune publication sur YouTube n’a été effectuée.
